# Isshi-hasegawa Tap

## How do I install these formulae?

`brew install isshi-hasegawa/tap/<formula>`

Or `brew tap isshi-hasegawa/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "isshi-hasegawa/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
